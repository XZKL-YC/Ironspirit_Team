# 分册四：算法（视觉）

> 定位：赋予机器人感知与决策能力。
> 对应竞赛：ROBOCON、智能汽车视觉组、智能机器人创意大赛。
> 建议起点：大一~大二。

## 1. 分册定位与目标

视觉方向负责让机器人"看得见、看得懂"。完成本分册后，你将具备：

- 基于 OpenCV 的图像处理能力；
- 训练与部署目标检测模型（YOLO）的能力；
- 视觉定位、跟踪与 3D 视觉/SLAM 的基础能力。

## 2. 先修要求

- Python 基础、线性代数基础。

## 3. 学习路线（四阶段）

### 阶段一：Python 与 OpenCV（大一~大二）

**目标**：掌握经典图像处理。

**知识点**
- Python、OpenCV（读写/滤波/边缘/颜色/轮廓/透视变换）、相机标定。

**实操任务**
1. 颜色识别。
2. AprilTag 定位。
3. 二维码识别。

**验收标准**：识别目标并输出其位置。

**推荐资源**：OpenCV 官方文档、B 站 OpenCV 教程。

### 阶段二：目标检测（大二）

**目标**：训练并部署目标检测模型。

**知识点**
- YOLO 系列、数据集制作、训练、OpenVINO / TensorRT 加速。

**实操任务**：训练一个目标检测模型并部署到嵌入式/工控机。

**验收标准**：目标检测实时、准确。

**推荐资源**：ultralytics/YOLO、[NEC 社区视觉课程](https://gitee.com/darrenpig/new_energy_coder_club)。

### 阶段三：视觉定位与跟踪（大二下~大三）

**目标**：实现运动目标定位与跟踪。

**知识点**
- 单目测距、PnP、卡尔曼跟踪、深度相机 / PCL。

**实操任务**：实现运动目标定位与跟踪。

**验收标准**：定位误差达标。

**推荐资源**：[中国石油大学 Robocon2024 视觉组开源代码](https://github.com/harbor302/Robocon2024)。

### 阶段四：3D 与 SLAM（大三~大四）

**目标**：掌握 3D 视觉与 SLAM 基础。

**知识点**
- SLAM、点云、强化学习 / Sim2Real。

**实操任务**：建图导航或强化学习策略。

**验收标准**：系统闭环。

**推荐资源**：[ROBOCON2026 官方仿真场景](https://github.com/discoverse-dev/ROBOCON2026)（MuJoCo + ROS2）。

## 4. 对应竞赛衔接

| 竞赛 | 所需阶段 | 主要工作 |
|------|----------|----------|
| 智能汽车视觉组 | 阶段二 | 目标识别与定位 |
| ROBOCON 视觉 | 阶段二~三（核心） | 识别、定位、跟踪 |
| 智能机器人创意大赛 | 阶段二~三 | 视觉应用 |

## 5. 常见误区与避坑

- 忽略传统视觉 → 传统 + 深度结合往往更稳、更快。
- 只会训练不会部署 → 训练只是第一步，部署才是竞赛关键。
- 不做数据管理 → 数据集版本化，标注可复现。
