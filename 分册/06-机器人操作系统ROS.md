# 分册六：机器人操作系统（ROS / ROS2）

> 定位：复杂机器人的软件架构与系统集成平台。
> 对应竞赛：ROBOCON、智能机器人创意大赛、智能汽车完全模型组。
> 建议起点：大一下~大二。

## 1. 分册定位与目标

ROS 方向负责把机械、电控、视觉各模块集成成一套完整的机器人系统。完成本分册后，你将具备：

- 在 Ubuntu 上开发 ROS2 应用的能力；
- 用 Gazebo/Rviz2 做仿真与可视化的能力；
- 建图、导航（SLAM/Navigation2）与硬件接口的基础能力。

> ⚠️ **重要提示**：ROS1 Noetic 已停止维护，新同学一律从 ROS2 入门。

## 2. 先修要求

- Linux 基础、C++ / Python 任意一种编程基础。

## 3. 学习路线（四阶段）

### 阶段一：Linux 基础（大一~大二）

**目标**：熟练使用 Ubuntu。

**知识点**
- Ubuntu、命令行、文件系统、权限、Shell。

**实操任务**：独立完成 Linux 日常操作。

**推荐资源**：鸟哥 Linux、B 站 Linux 入门。

### 阶段二：ROS2 核心（大二）

**目标**：掌握 ROS2 核心概念。

**知识点**
- ROS2 概念（节点/话题/服务/动作/参数/DDS）、工作空间、发布订阅、C++/Python。

**实操任务**：跑通入门教程，写一个话题通信节点。

**推荐资源**：古月居《[ROS2 入门 21 讲](https://class.guyuehome.com/p/t_pc/course_pc_detail/column/p_628f4288e4b01c509ab5bc7a)》、鱼香 ROS《动手学 ROS2》。

### 阶段三：仿真与建模（大二下）

**目标**：掌握仿真与建模工具。

**知识点**
- Launch、TF2、URDF、Gazebo、Rviz2。

**实操任务**：搭建仿真小车并可视化。

**推荐资源**：张瑞雷《ROS2 机器人高效编程》公开课、[古月学院](https://class.guyuehome.com/)。

### 阶段四：导航与实战（大三）

**目标**：实物机器人建图导航。

**知识点**
- Navigation2、SLAM（Cartographer）、MoveIt、硬件接口。

**实操任务**：实物机器人建图导航。

**推荐资源**：《[ROS 2 智能机器人开发实践](https://baike.baidu.com/item/ROS%202%E6%99%BA%E8%83%BD%E6%9C%BA%E5%99%A8%E4%BA%BA%E5%BC%80%E5%8F%91%E5%AE%9E%E8%B7%B5/65232885)》（2025，基于 ROS 2 Jazzy）。

## 4. 对应竞赛衔接

| 竞赛 | 所需阶段 | 主要工作 |
|------|----------|----------|
| ROBOCON | 阶段三~四 | 系统集成、协同控制 |
| 智能机器人创意大赛 | 阶段三~四 | 整机系统 |
| 智能汽车完全模型组 | 阶段三~四 | 模型车自主导航 |

## 5. 常见误区与避坑

- 学 ROS1 → 直接 ROS2，别浪费时间在停维护的版本上。
- 只会仿真不上实物 → 尽早真机验证。
- 不学 Linux 直接学 ROS → 先打好 Linux 基础。
