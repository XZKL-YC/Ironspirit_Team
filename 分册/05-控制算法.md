# 分册五：控制算法

> 定位：让机器人"稳、准、快"地运动。
> 对应竞赛：智能汽车、电子设计、ROBOCON。
> 建议起点：大二。

## 1. 分册定位与目标

控制方向负责机器人的运动与姿态控制。完成本分册后，你将具备：

- 建模与 PID 调参的能力；
- 速度环/位置环等运动控制的设计能力；
- 现代控制（LQR 等）与高级控制（MPC 等）的基础能力。

## 2. 先修要求

- 高等数学、线性代数、电路基础。

## 3. 学习路线（四阶段）

### 阶段一：经典控制与 PID（大二上）

**目标**：掌握建模与 PID。

**知识点**
- 传递函数、时域/频域分析、PID（位置式/增量式）、MATLAB/Simulink。

**实操任务**：Simulink 仿真 PID 调速并调参。

**验收标准**：能解释 PID 三参数作用并调出稳定系统。

**推荐资源**：自动控制原理教材、MATLAB 官方教程。

### 阶段二：运动控制（大二下）

**目标**：掌握多环运动控制。

**知识点**
- 速度环/位置环、前馈、抗积分饱和、滤波。

**实操任务**：平衡车（倒立摆）、循迹控制。

**验收标准**：平衡车稳定站立。

**推荐资源**：B 站控制类课程。

### 阶段三：现代控制（大三）

**目标**：掌握状态空间方法。

**知识点**
- 状态空间、状态反馈、LQR、观测器。

**实操任务**：用 LQR 实现平衡车/无人机控制。

**验收标准**：对比 PID 与 LQR 的性能。

### 阶段四：高级控制（大三~大四）

**目标**：接触前沿控制方法。

**知识点**
- MPC、自适应 / 自抗扰控制、最优控制。

**实操任务**：复杂系统控制（如多自由度机构）。

## 4. 对应竞赛衔接

| 竞赛 | 所需阶段 | 主要工作 |
|------|----------|----------|
| 智能汽车 | 阶段一~二（核心） | 循迹/平衡控制 |
| 电子设计（控制类） | 阶段一~二 | 运动控制 |
| ROBOCON | 阶段二~三 | 底盘/机构控制 |

## 5. 常见误区与避坑

- 只会调参不懂原理 → 先建模再调参。
- 不仿真直接上实物 → 先 Simulink 验证再上真机。
- 忽视传感器噪声 → 加滤波。
