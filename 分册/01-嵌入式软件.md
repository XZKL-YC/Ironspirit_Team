# 分册一：嵌入式软件

> 定位：机器人的"大脑与神经"，负责外设驱动、实时控制与通信。
> 对应竞赛：智能汽车、电子设计、ROBOCON、蓝桥杯。
> 建议起点：大一。

## 1. 分册定位与目标

嵌入式软件是所有实物类竞赛的底层能力，也是实验室人数最多、最核心的方向之一。完成本分册后，你将具备：

- 独立完成单片机外设驱动与电机闭环控制的能力；
- 使用 STM32CubeMX + HAL 的工程化开发能力；
- 用 FreeRTOS 组织多任务系统的能力；
- 参与智能汽车 / 电赛 / ROBOCON 电控工作的能力。

## 2. 先修要求

- 无强制先修；有 C 语言基础者可从阶段二开始。
- 建议同步具备：基础电路知识（能看懂原理图）。

## 3. 学习路线（四阶段）

### 阶段一：C 语言与单片机入门（约 4–6 周，大一上）

**目标**：掌握 C 语言核心语法，能用 51/STM32 点亮 LED、读按键、发串口。

**知识点**
- C 语言：变量与类型、指针、结构体、位运算、中断思想、状态机。
- 单片机：最小系统、GPIO、定时器、中断、串口、ADC。

**实操任务**
1. 点亮 LED 并实现流水灯。
2. 按键消抖与状态机。
3. 串口 printf 收发。
4. 定时器 PWM 呼吸灯。
5. 读取电位器 ADC 并在上位机显示。

**验收标准**：不看教程能独立写出"按键控制流水灯 + 串口打印状态"。

**推荐资源**：江协科技 STM32 入门（B 站）、正点原子 / 野火入门视频、C 语言教程。

### 阶段二：STM32 外设与 HAL（约 8–10 周，大一下~大二上）

**目标**：熟练使用 STM32CubeMX + HAL，掌握全部常用外设。

**知识点**
- CubeMX 配置；GPIO/EXTI、TIM（PWM/编码器/输入捕获）、ADC/DAC、USART/DMA、I2C、SPI、CAN。

**实操任务**
1. 用 CubeMX 生成工程并驱动外设。
2. 编码器测速。
3. PWM 驱动电机。
4. I2C 读取 MPU6050。
5. SPI 驱动 OLED 屏。
6. CAN 双机通信。

**验收标准**：独立完成"编码器 + 电机 PWM + 串口上位机显示转速"。

**推荐资源**：野火《[STM32 HAL 库开发实战指南](https://doc.embedfire.com/mcu/stm32/f767_h743_h750/hal_general/pdf/index.html)》、正点原子《手把手教你 STM32 HAL》、ST 官方 HAL 文档。

### 阶段三：RTOS 与实时控制（约 8 周，大二）

**目标**：用 FreeRTOS 组织多任务系统，实现电机闭环控制。

**知识点**
- FreeRTOS 任务/队列/信号量/互斥锁、软件定时器、临界区、优先级调度。

**实操任务**
1. 移植 FreeRTOS。
2. 搭建多任务框架：控制任务 + 通信任务 + 显示任务。
3. 电机速度环 PID（增量式）。
4. 位置环 + 速度环双闭环。

**验收标准**：用 RTOS 实现一台"双闭环调速小车底盘"，任务划分清晰、无阻塞。

**推荐资源**：野火 / 正点原子 FreeRTOS 教程、FreeRTOS 官方文档。

### 阶段四：嵌入式进阶与工程化（大三）

**目标**：面向竞赛的工程能力：性能、可靠、协作。

**知识点**
- DMA 链式、USB CDC、CAN 总线多节点、Bootloader、看门狗、日志框架、代码规范与模块化。

**实操任务**：把阶段三的小车重构为"模块化 + 日志 + 看门狗 + 上位机调参"的工程。

**验收标准**：代码可维护、可多人协作、异常可恢复、有调参工具。

**推荐资源**：安富莱 / 韦东山进阶教程、开源车队电控工程。

## 4. 对应竞赛衔接

| 竞赛 | 所需阶段 | 主要工作 |
|------|----------|----------|
| 蓝桥杯（单片机组） | 阶段一~二 | 单片机应用设计 |
| 智能汽车 | 阶段二~三 | 循迹/平衡电控、通信 |
| 电子设计（控制类） | 阶段二~三 | 控制系统实现 |
| ROBOCON 电控 | 阶段三~四 | 底盘/机构电控、CAN 总线 |

## 5. 常见误区与避坑

- 只看视频不动手 → 每个知识点配一个实操任务，亲手调通。
- 迷信标准库 → 新项目统一 HAL + CubeMX（ST 官方主推）。
- 只会 printf 调试 → 尽早学会 ST-Link 单步 + 逻辑分析仪。
- 代码堆在一起 → 从一开始就模块化、分层，便于复用与协作。
