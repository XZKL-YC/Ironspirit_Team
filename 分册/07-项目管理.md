# 分册七：项目管理

> 定位：把个人技术转化为团队成果，贯穿所有竞赛。
> 对应竞赛：贯穿全部，ROBOCON 尤重。
> 建议起点：大一（工具），大三（带队）。

## 1. 分册定位与目标

项目管理是团队竞赛成败的关键软实力。完成本分册后，你将具备：

- 用 Git 与文档规范维护工程的能力；
- 制定赛季计划、拆解需求与推进进度的能力；
- 带队完成一个完整赛季并做好传承的能力。

## 2. 学习路线（三阶段）

### 阶段一：工具与规范（大一）

**目标**：掌握协作与文档工具。

**知识点**
- Git/GitHub/Gitee、Markdown、技术文档规范。

**实操任务**：独立维护个人代码仓库 + 技术笔记。

**验收标准**：自己的学习成果全部可追溯、可复用。

**推荐资源**：Git 官方教程、Markdown 语法。

### 阶段二：赛季管理（大二~大三）

**目标**：掌握赛季级项目推进方法。

**知识点**
- 赛季时间规划、需求拆解、分工、进度看板、技术评审。

**实操任务**：制定一份赛季计划书。

**验收标准**：计划可执行、进度可追踪、风险有预案。

### 阶段三：带队与传承（大四）

**目标**：具备带队能力。

**知识点**
- 风险与应急管理、知识库沉淀、答辩与成果展示。

**实操任务**：带队完成一个完整赛季并沉淀复盘文档。

**验收标准**：团队成果可持续、下一届可接手。

## 3. 对应竞赛衔接

- 蓝桥杯：阶段一。
- 智能汽车 / 电子设计 / 创意大赛：阶段一~二。
- ROBOCON：阶段一~三（核心）。

## 4. 常见误区与避坑

- 无文档 → 从第一天开始写文档，边做边记。
- 无版本管理 → 一切代码与图纸进 Git。
- 无进度管理 → 赛季初就定里程碑，定期技术评审。
