## 一、实验室培养理念

- 核心定位：**实物制作为导向、竞赛为牵引、工程能力为核心**，拒绝"只会考试、不会动手"。
- 价值观：鼓励挑战有难度的实物类赛题；宁可做深一个方向，不要样样浅尝辄止。
- 三大能力目标：**能独立做出东西（单兵）→ 能做出可靠的东西（工程化）→ 能带团队做出东西（传承）**。

## 二、五大竞赛与七大技术方向的总关系

- 竞赛图谱：蓝桥杯（入门级）→ 智能汽车 / 电子设计 / 智能机器人创意大赛（进阶）→ ROBOCON（综合主力）。
- 方向图谱：嵌入式、硬件、机械、视觉、控制、ROS、项目管理，七方向互为上下游，实物机器人是共同载体。

## 三、分层培养体系（大一 → 大四）

### 大一 · 基础夯实期
- 目标：建立编程与电路基本功，完成第一件能动的实物。
- 能力要求：C 语言、电路与数模电基础、51/STM32 入门、机械制图、Git 基础。
- 建议竞赛：蓝桥杯（C/C++、单片机组）、智能汽车基础组 / 创意赛基础赛道。
- 里程碑作品：可编程小车 / 简易循迹车 / 最小系统板。

### 大二 · 方向分化期
- 目标：选定 1–2 个技术方向深耕，具备独立完成子模块的能力。
- 能力要求：在所选方向达到"进阶"段位，能读通官方文档与开源项目。
- 建议竞赛：智能汽车竞速组、电子设计竞赛、智能机器人创意大赛。
- 里程碑作品：平衡车 / 全向移动底盘 / 一块完整的电机驱动板。

### 大三 · 竞赛主力期
- 目标：作为主力队员承担完整系统，冲击省赛/国赛奖项。
- 能力要求：多方向协同能力，掌握项目管理与赛季节奏。
- 建议竞赛：ROBOCON、智能汽车国赛、电子设计竞赛国赛。
- 里程碑作品：一整台能稳定完成任务的比赛机器人。

### 大四 · 传承领航期
- 目标：从"做"到"带"，负责技术把关、方案评审与梯队培养。
- 能力要求：技术评审能力、文档沉淀、答辩与成果转化（毕业设计、论文、专利）。
- 建议角色：队长 / 技术负责 / 方向导师。

## 五、阶梯式实践里程碑与考核

### 必修项目序列（通用主线）
1. 点亮一颗 LED + 串口打印（嵌入式第一课）
2. 电机闭环调速 + 一块自制驱动板（硬+软）
3. 循迹车 / 平衡车（控制入门）
4. 全向移动底盘（机械+电控+控制）
5. 视觉目标识别 + 抓取（视觉+机械）
6. 一台 ROS2 仿真机器人建图导航（ROS）
7. 一台能完成竞赛任务的完整机器人（综合）

### 阶段考核与准入
- 大一末：独立完成基础小车 → 进入正式备赛梯队。
- 大二末：方向作品答辩 + 一次完整竞赛经历 → 进入主力梯队。
- 大三：以竞赛名次与系统贡献度为考核。
- 考核形式：**实物演示 + 技术答辩 + 代码/图纸归档**。

## 六、实验室制度与梯队建设

- 资源平台：单片机/开发板、3D 打印机、机加工、示波器/电源/万用表；Git 仓库、仿真环境、文档库。
- 导师/学长制：高年级带低年级的"老带新"结对；每方向设一名技术负责人；每两周一次技术分享会。
- 出队与传承：毕业生离队需完成技术交接与文档归档，形成可持续的梯队闭环。

## 七、常用工具链（速查）

- 嵌入式：Keil/IAR、STM32CubeMX、ST-Link/J-Link
- 硬件：嘉立创 EDA / Altium Designer、示波器、电烙铁
- 机械：SolidWorks、3D 打印机
- 视觉：Python、OpenCV、ultralytics/YOLO
- 控制：MATLAB/Simulink
- 机器人：Ubuntu、ROS2、Gazebo、Rviz2
- 管理：Git/GitHub/Gitee、Markdown
