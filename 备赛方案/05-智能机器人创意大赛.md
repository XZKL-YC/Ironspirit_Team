# 备赛方案：中国高校智能机器人创意大赛

> 实验室定位：综合，创意落地，多方向协作。
> 建议年级：大二~大三。

## 1. 竞赛概览

- 性质：以创意、AI、机器视觉、ROS 为主要开发内容，强调创意落地。
- 赛程：校赛 → 省赛 → 国赛，周期较长。
- 特点：技术门槛相对灵活，适合把实验室积累的技术做成有创意的完整作品。

## 2. 技术栈

- ROS/ROS2、视觉（目标检测/识别）、机械结构、嵌入式。

## 3. 备赛时间轴

| 阶段 | 时间 | 主要工作 | 里程碑 |
|------|------|----------|--------|
| 选题 | 赛季初 | 创意选题、可行性分析 | 选题定稿 |
| 方案 | 赛季前期 | 技术方案、分工 | 方案评审通过 |
| 实现 | 赛季中期 | 机械/电控/视觉/系统开发 | 原型完成 |
| 展示 | 赛季后期 | 整机完善、答辩准备 | 完整作品 + 答辩 |

## 4. 团队分工

- 多方向协作：机械 + 嵌入式 + 视觉 + 系统集成 + 文案/答辩。

## 5. 阶段里程碑与验收

1. 创意 → 2. 原型 → 3. 完整系统 → 4. 答辩展示。
- 关键验收：作品能现场稳定演示，答辩材料完整。

## 6. 采购与资源

- 按作品需求采购；资源：官方通知、历届获奖作品。

## 7. 常见误区与避坑

- 创意贪大、不可落地 → 选题要可落地、可演示。
- 忽视展示与文档 → 演示效果和答辩材料同等重要。

## 8. 在实验室中的衔接

- 创意大赛适合把各方向的阶段性成果整合成作品，是 ROS + 视觉方向的良好练手，也是从模块到整机的过渡。
